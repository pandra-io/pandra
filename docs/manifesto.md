# About Pandra

Pandra was created to streamline the AI agent experience - To redefine how we create, pack, share, deploy, and run agents.

We draw inspiration from existing tools and practices which we love using every day, and want Pandra to hold up and carry forward the same principles.

We hope that Pandra will become a staple of the AI agents ecosystem, and will inspire users and developers to use and build agents.

## Create Agents as Code
Pandra is a development framework for agents. It is fully declarative and relies on familiar Markdown and YAML foundations.  
This approach allows you to employ mature software development practices - track and review change in Git, collaborate with colleagues, use code review and release pipelines - all without writing code, or locking into a programming ecosystem and toolchain.

## Share and Deploy Agents
Pandra is a package manager for agents. It relies on standard Git repositories and container registries for distributing agents.  
This approach lets you easily share agents between people and environments - privately, anonymously, organizationally or publicly, no special infrastructure or setup is required.

## Write Once, Run Anywhere
Pandra is a harness-agnostic agent execution engine. It runs portable agent packages with existing AI harnesses as execution targets.  
This approach allows developers to reach more users and users to benefit from more agents, encouraging the proliferation of agent applications.

## Bring Your Own AI
Pandra is a vendor neutral agent execution engine. It lets you use the same AI vendors and tools you know and trust today.  
This approach allows you to reuse your existing subscriptions, organizational policies and tooling.

## Manage skills at scale
Pandra is a skill management paradigm. It promotes that agents carry their own skills, so you don't need to install skills locally, in repositories, or to think about skills at all.  
This approach is a practical way to organize skills across environments, projects, and teams.

## Automate with agents
Pandra is a scriptable agent runner. It can run agent packages non-interactively to completion. This approach lets you integrate agents in scripts, CI/CD pipelines, batch jobs, and other automated workflows.

## Isolate harness configurations
Pandra is a harnesses virtual environment manager. It automatically creates ephemeral configuration folders for each agent execution.  
This approach allows easy invocation of ad-hoc or temporary agents without polluting your global or project configuration with agent-specific configuration, and while preventing existing global configurations from leaking into executed agents, which ensures predictable and consistent results.

## Enjoy Agents Everyday
Pandra is designed with power-users in mind, while striving to balance convenience and control. It is CLI-first, Developer-friendly, and zero-configuration by default.  
This approach makes it fun and easy to discover, try, and leverage agents in our work and life styles.

## Build with Pandra
Pandra is open source and open standards. It is open and licensed permissively, and its concepts are standardized and externalized.  
This approach makes it possible for different tools or vendors to collaborate and integrate, to the benefit of the greater community.
