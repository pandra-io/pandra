# Pandra

Pandra defines, packages, shares, and runs AI agents on the coding harnesses you already use (Claude Code, Codex, and Pi).

The source code is not published yet. This repository holds the release binaries and the example agents that the documentation uses.

- Documentation: https://pandra.io
- Installation: https://pandra.io/installation
- Example agents: [examples](examples/README.md)
